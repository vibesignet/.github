# Vibesignet

Website templates with tested build prompts for Claude Code, Codex and Cursor. Each template is a finished, working home page with a live demo, and the prompt that recreates it.

- **[website-prompts](https://github.com/vibesignet/website-prompts)**: three free prompts, a brief, three design directions and a hero build prompt, with the demo an AI coding agent built from it.
- **[The library](https://vibesignet.com)**: every template, live. A free account unlocks one template of your choice.
- **[How to build a website with Claude Code](https://vibesignet.com/guides/build-a-website-with-claude-code)**: the seven steps, from brief to phone test.
- **MCP server**: `https://vibesignet.com/api/mcp`, so Claude Code, Codex or Cursor can search the library and fetch a prompt. Setup: [Claude Code](https://vibesignet.com/for/claude-code), [Codex](https://vibesignet.com/for/codex), [Cursor](https://vibesignet.com/for/cursor).
